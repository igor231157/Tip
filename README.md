# Репозиторий по дисциплине "Технологии индустриального программирования"

## Описания
Данный репозиторий используется для загрузки решений практических занятий по вышеуказанной дисциплине.
Все решения буду находится в папках с номером соответсвующей практической работы.
Папки будут хранится в едином репозитории

> **P.s. Оформление файлов описания README.md не несёт никакого смысла и создано исключительно для эстетитечского удовлетворения автора.**

# Структура репозитория
- `README.md` - главный, глобальный файл с описанием;
- `.gitignore` — список файлов, исключённых из Git;
- - `practice-0..` - директория соответствующей практическй работы;
- - - `README.md` - файл с описанием текущей практической работы;
- - - `...` - файлы решения текущей практической работы;
