### Запуск через браузер: 

1. В HTML указать нужный файл в атрибуте `src`, например:

   ```html
   <script src="./js/debug.js" defer></script>
   ```
2. Открыть `practice-01/index.html` в браузере.
3. Открыть инструменты разработчика (F12) и вкладку *Console*.
4. Для другого задания заменить `src` на `./js/hello.js`, `./js/progress.js`, `./js/plan.js`, `./js/types.js`, или `./js/debug_correct.js`.
5. Сохранить изменения и перезагрузить страницу.

Одновременно подключается только один учебный файл: повторяющиеся объявления верхнего уровня в нескольких классических скриптах могут вызвать ошибку. Для удобства написания, временно не используемые подключения скриптов были обернуты в комментарий `<!-- ... -->`. Атрибут `defer` откладывает выполнение внешнего классического скрипта до завершения разбора HTML. Вывод `console.log()` находится в консоли, а не в содержимом страницы.

## Задания:  
### Задание №1:

Программа `hello.js` выводит имя студента, группу, номер практической работы, сообщение об успешном запуске и результат выражения `typeof document`.

| Среда | Способ запуска | Место вывода | Результат последней строки |
|---|---|---|---|
| VS Code + Node.js | node practice-01/js/hello.js | Терминал VS Code | "undefined" |
| Браузер | Открытие HTML с подключённым hello.js | Console в DevTools | "object" |

**Объяснение различия.** JavaScript — язык программирования, а Node.js и браузер — среды его выполнения. Браузер предоставляет объект `document`, представляющий загруженный HTML-документ. Обычный запуск в Node.js не создаёт страницу и не предоставляет браузерный DOM. Оператор `typeof` позволяет безопасно проверить необъявленный в этой среде идентификатор `document` и получить строку `"undefined"`.

### Задание №2:

| Выражение | Моё ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
|---|---|---|---|---|
| "8" + 2 | 82 | "82" | string | При строковом операнде + объединяет текст: число 2 преобразуется в строку. |
| "8" - 2 | Error | 6 | number | Оператор вычитания преобразует строку "8" в число. |
| Number("8") + 2 | 10 | 10 | number | После явного преобразования оба операнда являются числами, поэтому выполняется сложение. |
| "12" > "3" | true | false | boolean | Две строки сравниваются лексикографически; первый символ "1" меньше "3". |
| 12 === "12" | Error | false | boolean | Строгое равенство не преобразует типы; число и строка различаются. |
| Number("") | NaN | 0 | number | Пустая строка при числовом преобразовании даёт ноль. |
| Number("text") | Error | NaN | number | Строка не содержит допустимую запись числа; результат — специальное числовое значение NaN. |
| Boolean("false") | false | true | boolean | Любая непустая строка даёт true; её текст не интерпретируется как логическое значение. |
| typeof null | null | "object" | string | Историческая особенность оператора: null — примитивное значение, но typeof null возвращает строку "object". |
| typeof NaN | NaN | "number" | string | Само значение NaN относится к числовому типу; результат оператора typeof — строка. |

В последних двух строках важно различать исследуемое значение и результат выражения. Например, `typeof NaN` имеет значение `"number"`, а `typeof (typeof NaN)` — `"string"`.
